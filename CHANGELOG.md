# Changelog

## 1.0.0 — Initial public release

- Poster-based movie and TV library with responsive navigation.
- Recursive folder scanning and periodic detection of new media.
- TMDB metadata/artwork integration with local filename fallback.
- VLC playback, Continue Watching, progress persistence, and Watchlist.
- Series detail browser with season and episode selection.
- Five-minute end-credit completion threshold and next-episode prompt.
- Opt-in permanent deletion with guarded source-folder boundaries.
- SQLite storage and local artwork caching.
